# Portfólio Ederson

Portfolio pessoal desenvolvido para apresentar informações sobre mim, projetos, formação, ferramentas e formas de contato.

## Sobre o projeto

Este repositório contém um site portfólio em HTML, CSS e JavaScript, com layout moderno, foco em visual limpo e tema claro/escuro. A página inclui seções de:

- apresentação inicial
- sobre mim
- projetos
- formação
- ferramentas
- contato

## Ferramentas utilizadas

- HTML5
- CSS3
- JavaScript ES Modules
- GitHub API para carregar projetos
